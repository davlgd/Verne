**Brisk** started in 2024 as a weekend project to make a personal site
rebuild fast enough to use during writing — incremental, in process, no
cold starts. It is now a small static site generator with a real user base
and a working plugin system.

This blog is where we write about the design decisions, the parts we got
wrong, and the corners of the web platform we keep finding new uses for.
